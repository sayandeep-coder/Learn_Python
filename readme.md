# 🐍 Python Basics Learning Repository

Welcome to my **Python Basics Learning Repository**!  
This repo contains beginner-friendly Python code examples and notes to help understand the core fundamentals of Python programming.

---

## 📘 Topics Covered

### 🔹 1. Variables & Data Types
- Introduction to variables
- Primitive data types: `int`, `float`, `str`, `bool`
- Type casting and `type()` function
- Input and output in Python

### 🔹 2. Operators
- Arithmetic Operators (`+`, `-`, `*`, `/`, `//`, `%`, `**`)
- Comparison Operators (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- Logical Operators (`and`, `or`, `not`)
- Assignment Operators (`+=`, `-=`, etc.)
- Identity & Membership Operators (`is`, `in`)

### 🔹 3. Data Structures
#### 🧩 List
- Creation, indexing, slicing
- Common methods (`append()`, `remove()`, `sort()`, etc.)
- Iterating through lists

#### 🧱 Tuple
- Immutable sequences
- Packing and unpacking

#### 🔑 Dictionary
- Key-value pairs
- Adding, updating, and deleting items
- Iterating over keys and values

#### 🧮 Set
- Unique unordered elements
- Set operations: union, intersection, difference
